# Occupify Agentic Features

This directory contains feature-specific agents, schemas, routers, and services for Occupify.

Current features:
- `chat/`: General Career Assistant chat supporting sessions, history replay, and PDF CV/portfolio attachments.

Planned features (see §11 Later):
- `roadmap/`: UC1 - Personalized Career Roadmap Agent
- `cv_match/`: UC2 - CV–Job Description Matching & Improvement Agent
- `applicant_ranking/`: UC3 - Intelligent Applicant Ranking Agent
- `job_recommendation/`: UC4 - Personalized Freelance Job Recommendation Agent
- `project_draft/`: UC5 - Project Requirement Analysis Agent
