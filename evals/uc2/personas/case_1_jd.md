Tiêu đề: Python Backend Developer (FastAPI / Redis / Docker)

- Thành thạo lập trình bất đồng bộ (AsyncIO, async/await).

- Có kinh nghiệm với Docker và quy trình kiểm thử tự động (Pytest).
