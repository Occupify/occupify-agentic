# Occupify Skill Library

The Skill Library contains domain-specific AI prompt packages executed by autonomous agents. Each skill is encapsulated in a directory containing instructions, schema references, and verifiable examples.

## Directory Structure

```
skills/
├── README.md
├── catalog.md                          # Auto-generated by `make skills-catalog`
├── _shared/
│   └── references/                     # Shared references across multiple skills
│       ├── vi-en-terms.md
│       ├── skill-equivalences.md
│       └── output-style.md
├── candidate/
│   └── extract-candidate-profile/      # CV text -> CandidateProfile
│       ├── SKILL.md
│       ├── references/
│       └── examples/
│           ├── case1.input.md
│           └── case1.output.json
├── matching/
│   ├── match-skills/                   # Job skills vs profile -> SkillMatchResult
│   └── assess-job-fit/                 # Requirement checking -> ProjectAssessment
└── search/
    └── plan-job-search/                # Multi-round job search -> SearchDecision
```

## Naming Conventions
- Domain directory: lowercase noun category (`candidate`, `matching`, `search`).
- Skill directory: `<verb>-<object>` (e.g. `extract-candidate-profile`, `match-skills`).
- Rule: **Extend before adding**. If an existing skill covers the domain, improve its prompt and reference cases before introducing a new skill.

## Frontmatter Specification

Every `SKILL.md` must start with YAML frontmatter:

```yaml
---
name: extract-candidate-profile
description: Extracts structured candidate profile, skills, roles, and domains from cleaned CV text.
output: app.skill_schemas.candidate.CandidateProfile
shared_references:
  - vi-en-terms.md
  - skill-equivalences.md
  - output-style.md
tools: []
used_by:
  - job-match
---
```

## Add-a-Skill Checklist
1. Create `skills/<domain>/<name>/SKILL.md` with required frontmatter.
2. Define the Pydantic output model in `app/skill_schemas/`.
3. Add at least two synthetic examples in `examples/` (`.input.md` and `.output.json`).
4. Validate library: `make skills-check`
5. Regenerate catalog: `make skills-catalog`
